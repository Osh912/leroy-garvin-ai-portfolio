# Recruiter Overview — GH-X MEO Airtable System

**Date:** 2026-07-20  
**What it is:** An Airtable operations database for a digital-product content and publishing pipeline (GH-X).

## What the system does
- Tracks digital products from idea to live listing
- Stores design/asset URLs, publish/QA/social statuses, and error logs
- Queues social content and video/script content for downstream tools
- Holds brand/default settings used by automation
- Provides a simple KPI/goals dashboard row

## Why it matters for AI Operations roles
Shows ability to design a **queue-based system of record** that AI/automation workflows can read and write — status fields, error logging, stage views, and content artifacts — without claiming unsupported production metrics.
