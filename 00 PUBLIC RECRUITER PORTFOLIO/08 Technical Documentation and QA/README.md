**Who this is for:** Recruiters evaluating documentation discipline and AI QA habits  
**Public status:** Process documented · sample screenshots Evidence Pending

## Business problem
AI and automation systems degrade when failures are not classified, fixed, and retested. Without documentation, improvements cannot be repeated or explained in interviews.

## My role
I wrote structured QA methods, failure classifications, root-cause notes, and portfolio documentation for the Voice Assistant and GH-X reliability workflows (Content QA, Self-Healing QA, Error Alerts—as definitions).

## Solution
A repeatable QA loop: define expected behavior → test → classify → root cause → fix → retest → document. Applied to conversational flows and automation reliability design.

## Technologies used
ChatGPT/Claude for analysis support · n8n QA/reliability workflow definitions · Airtable status/error fields · markdown process documentation
