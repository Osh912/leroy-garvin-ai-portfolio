## Privacy Gate (Every Image)
Before attaching any screenshot:
- [ ] No customer names, phones, or full addresses
- [ ] No API keys, tokens, webhooks, or credentials
- [ ] No private financials
- [ ] Caption states what the image proves (design / test / fix / document)
- [ ] Scope matches documentation (concept/planned/tested — not fake production)
