# EVIDENCE_PRIVACY_GATE.md

Run this checklist before attaching **any** screenshot or workflow export to the portfolio or GitHub.

## Credentials & secrets
- [ ] API keys
- [ ] OAuth credentials
- [ ] Access tokens
- [ ] Webhook URLs (especially those embedding secrets)
- [ ] Twilio credentials
- [ ] OpenAI credentials
- [ ] Airtable tokens
- [ ] Supabase keys
- [ ] Etsy / Metricool / HeyGen / Google credential panes

## Personal / customer data
- [ ] Customer names
- [ ] Customer phone numbers
- [ ] Customer addresses
- [ ] Email addresses (non-public)
- [ ] Financial information
- [ ] Private browser tabs
- [ ] Personal messages
- [ ] Internal IDs that should not be public

## Claim safety
- [ ] Caption matches truthful status (Prototype / Functional Build / In Progress)
- [ ] No “production”, “live customers”, or “successful run” claim without execution evidence
- [ ] Scope matches written docs
