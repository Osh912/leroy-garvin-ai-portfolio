## 9-Step QA Method (Say This Clearly)
1. Define expected behavior  
2. Create test scenario  
3. Run test  
4. Compare actual vs expected  
5. Classify failure  
6. Root cause analysis  
7. Apply fix  
8. Retest  
9. Document issue, cause, fix, remaining risk
