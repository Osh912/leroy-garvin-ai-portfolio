# Screenshot Index — Employer Evidence Pack

## Recruiter Summary
This folder is the visual evidence pack for the AI Operations portfolio. Each file below lists the exact screenshots to capture for a project, what each image should prove, and the privacy rules before sharing. **Images are not yet attached**—checklists are ready so evidence can be added without inventing production dashboards or unsupported claims.

**How to use (2 minutes):**
1. Start with the Minimum Viable Proof list below.
2. Open the matching evidence file for caption and checklist details.
3. Confirm Captured? / Sanitized? before sending to employers.

## Privacy Checklist (Complete Before Sharing)
- [ ] No customer names, phone numbers, or full addresses visible
- [ ] No API keys, tokens, webhook URLs, or credentials
- [ ] No private business financials
- [ ] Blur or crop sensitive Airtable/Twilio/n8n fields as needed
- [ ] Confirm screenshot matches the written claim in resumes/LinkedIn
- [ ] Caption states what the image proves (design / test / fix / document)

## Truthfulness Rules
- Do not invent screenshots or claim production dashboards that do not exist.
- Prefer honest “design / test / document” visuals over exaggerated production claims.
- Cursor Development is **evidence of AI-assisted documentation work**, not a separate software product deployment.
- GH-X, n8n, and Airtable visuals should match concept/planning/testing scope already documented in project folders.
