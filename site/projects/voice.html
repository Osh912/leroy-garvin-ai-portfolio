Problem

Missed or unstructured calls created incomplete customer data, unclear service requests, pricing confusion, and unreliable appointment confirmation.

Solution

Designed a 10-stage booking flow with one-question-at-a-time behavior, pricing confirmation checkpoints, address/ZIP collection, appointment options, and a professional close.

My role

Owned conversation logic, prompt strategy, business rules, testing, root-cause fixes, and documentation for the service business.

Tools used

ChatGPT for prompt design; documented n8n/Airtable/Twilio in project scope; structured QA notes.

Challenges

Loops, repeated questions, incorrect booking order, pricing confirmation gaps, and address handling failures during tests.

What I improved

Stage control, confirmation checkpoints, clearer failure classification, and a define → test → fix → retest documentation habit.

Verified outcome

Documented 10-stage Functional Build with published sanitized documentation screenshots. Qualitative reduction of recurring failure patterns in testing notes — no call-volume or conversion metrics claimed.
