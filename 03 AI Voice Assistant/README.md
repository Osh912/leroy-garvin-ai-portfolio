# AI Voice Booking Assistant — README

## What This Project Is
An AI-assisted voice booking workflow designed for Right Outside Auto Detailing LLC (Savannah, Georgia) to support customer service conversations, pricing confirmation, and appointment booking through structured stages, prompt engineering, and iterative testing.
